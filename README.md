# Azzurri Arcade

Ретро-аркадный футбол в духе Goal 3 (Dendy): вид сбоку, чиби-игроки, подкаты без правил, погода,
КАОС-события и пародийные суперудары (ТИГРОПЕНДАЛЬ, КЕФИРХАМЕХА, ВЕРТОПЕЛЬМЕНЬ, НА-НА-НА).
- **КАРЬЕРА** — свой клуб или свой игрок, мировое турне из 8 матчей с перелётами по странам. С сюжетом-пародией: агент Жора, пресс-конференции, президент с требованиями, соперник-брат-близнец, гусь и «Золотой мяч».
- Перед матчем выходят талисманы команд (Багетто, Крендель, Сэр Чай…), два тайма с перерывом и сменой ворот.
- У каждой страны свой скилл (табун Монголии, метель Антарктиды, забастовка Франции…), кнопка БУ! и нелепицы.
- **АРКАДА: 1 на 1, 2 на 2 и 11 на 11** — 18 стран (от Казахстана и Франции до Антарктиды и Атлантиды), 12 разных полей со своей физикой и зверями.
- Вратари с нырками и сейвами, 4 уровня сложности: Я СЛАБАК, Я НОРМ, Я МУТАНТ, Я ЧУДОВИЩЕ.

## Играть
**https://junussovalan02-bot.github.io/Football-2S/** — сайт обновляется сам после каждого пуша
(`.github/workflows/pages.yml`). Один раз нужно включить: Settings → Pages → Source: **GitHub Actions**.

С другом: ИГРАТЬ → С ДРУГОМ → выбери режим → появится код из 5 символов → «ПОДЕЛИТЬСЯ».
Друг открывает ссылку или вводит код в «ВОЙТИ ПО КОДУ». Сервер не нужен: телефоны соединяются
напрямую через WebRTC (PeerJS).

## Запуск локально
```
npx --yes serve -l 8080 .
```
Открыть http://localhost:8080 (на телефоне — по адресу компьютера в той же Wi-Fi сети).

Проверить онлайн без сервера: открыть `http://localhost:8080/?net=local` в двух вкладках.

Собрать один HTML-файл: `python3 tools/build-single.py` → `dist/azzurri-arcade.html`.

Автотест на размерах телефона: `python3 tools/playtest.py` → скриншоты в `playtest/`
(один раз нужно: `pip install playwright && python3 -m playwright install chromium`).
